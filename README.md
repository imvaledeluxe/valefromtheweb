# valefromtheweb

## Abrir el proyecto
1. Descomprime la carpeta.
2. Abre Visual Studio Code.
3. Selecciona File > Open Folder y elige `valefromtheweb`.
4. Abre `index.html` con Live Server (extensión de VS Code), o abre el archivo directamente en tu navegador.

## Qué incluye esta primera versión
- Diseño editorial adaptable a móvil y escritorio.
- Archivo de entradas de ejemplo.
- Búsqueda y filtros por categoría.
- Formulario para escribir y guardar entradas.
- Lectura de cada entrada en una ventana.
- Modo oscuro.

## Importante sobre el guardado
Las entradas se guardan en el almacenamiento local del navegador y dispositivo donde las escribas. Todavía no existe una cuenta, base de datos ni publicación compartida en internet. Para publicar y sincronizar entre dispositivos, después conectaremos el sitio a un servicio de base de datos o a un CMS.

## Archivos
- `index.html`: estructura.
- `style.css`: diseño.
- `script.js`: interactividad y guardado local.


La imagen `foto-vale-bn.jpg` se utiliza en la sección Sobre mí. Mantén este archivo junto a `index.html`.


## Editor visual
Abre `admin.html` con Live Server para personalizar colores, tipografías, tamaño de texto, ancho, espaciado y composición. Los cambios se guardan en el almacenamiento local del navegador y se aplican a `index.html`. No necesitas editar CSS para estos ajustes.

Nota: esta primera versión guarda la configuración en el navegador de tu computadora. Para que el diseño personalizado se conserve y se vea igual en otros dispositivos al publicar el sitio, habrá que incorporar la configuración al despliegue o conectarla a una base de datos.
